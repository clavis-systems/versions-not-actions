# Premessa: modifiche fallite e sprecate negli agenti che programmano

Regole fissate prima della corsa sui dati tenuti da parte, per l'articolo della Gemma 4 Developer Agent Paper
Track. Si congela con un commit; dopo, ogni cambiamento va nella sezione «Scostamenti», con data e motivo.

## 0. Precedenti e perimetro

Il controllo di novità di Codex (`strumenti/esperimenti_codex/NOVITA_VISTE_VECCHIE.md`, 09/10, 20 fonti più un
seguito) ha trovato precedenti diretti. **Non rivendichiamo come nuovi** questi punti:
- **Misurare le viste vecchie in molte esecuzioni reali.** FreshCtx (Basurto, 23/09/2026) conta le richieste con
  viste superate in 67.074 esecuzioni OpenHands con Qwen3-Coder-480B su SWE-rebench.
- **Sincronizzare o invalidare il contesto prima dell'azione:** CORVUS (arXiv 2607.22711), Concord (arXiv
  2610.05281), le ancore di Hashline.
- **Contare le modifiche fallite e il recupero, e confrontare editor e modelli:** SWE-agent (arXiv 2405.15793,
  B.3.3), Gupta et al. (arXiv 2606.17454, 153.990 traiettorie), Thakur (20/02/2026: errori, rivisite e cicli di
  modifica), Hashline, Aider.
- **Ricordare tentativi e versioni con i risultati delle prove:**

  0.62.0 le regole sono diverse.

**Cosa proviamo a sostenere**, e solo nei limiti di questa premessa:
1. **Una risorsa controllabile di incidenti** su esecuzioni pubbliche di più modelli:
   - due assi separati: l'esito meccanico dello strumento e la prova disponibile sullo stato del file;
   - denominatori espliciti, casi ignoti contati;

   l'host ricorda quale prova era fallita mentre quel blocco c'era.

## 3. Rilevatori e misure

Il codice (`rilevatori.py` versione 2 e `misura.py`, con le impronte SHA-256 nel file di avvio e nei risultati)
applica le definizioni esatte della §9. Qui c'è il riassunto. Ci sono **due assi**, da non confondere.

**Esito di ogni chiamata dell'editor: riuscito, errore o sconosciuto.**
- Il risultato di una chiamata è il messaggio dello strumento con lo stesso identificativo. Senza identificativi è
  quello nella stessa posizione, se il numero dei risultati è uguale a quello delle chiamate; altrimenti manca.
- La chiamata è riuscita solo se il messaggio di successo corrisponde al comando.
- Un risultato vuoto, mancante o non riconosciuto è «sconosciuto»: non conta né come riuscito né come fallito ed è
  riportato a parte.

**Asse 1: esito meccanico di `str_replace`**, dal messaggio dell'editor:
- noop: testo nuovo uguale al vecchio («must be different»);
- missing: il testo vecchio non c'è («did not appear verbatim»);
- multiple: il testo vecchio compare più volte;
- other: ogni altro errore.

**Asse 2: prova disponibile sullo stato, solo per missing.** I testi visti sono:
- le letture riuscite del file;
- i pezzi mostrati dopo le modifiche;
- le letture semplici da bash, anche la prima di un file mai visto;
- il testo scritto dall'agente stesso.

Le classi:
- vista vecchia: il testo era in un testo visto e il file è cambiato dopo;
- errore di copia negli spazi;
- visto e non modificato;
- **non osservato nel log:** non vuol dire «inventato».

Un comando bash che può scrivere il file lo segna come «forse modificato». È una prova incerta, dichiarata come
tale.

**Modifiche nulle.**
- Cause, nell'ordine: già applicata, ripetizione, dopo un comando fallito (codice d'uscita diverso da 0, o
  un'espressione d'errore), altro.
- Esito: stesso punto, altrove nello stesso file, mai più.
- Costo osservato: le chiamate fino alla modifica riuscita successiva dello stesso file, compresa.
  - Le modifiche nulle mai seguite da una modifica riuscita sono contate a parte.
  - Mediana usuale.
  - Non è un risparmio causale.

**Ritorni (memoria delle versioni).** L'identità è il **testo del blocco dentro un percorso**, con almeno una riga
di 8 caratteri. Il resto del file e del progetto può essere diverso.

**Presenza certa (regola prudente).** La presenza di un blocco è certa dal momento in cui l'agente l'ha scritto con
un `str_replace` riuscito fino al **prossimo cambiamento qualsiasi dello stesso file**. Contano come cambiamento:
- un altro `str_replace` riuscito, anche lontano dal blocco;
- un insert, un create o un undo;
- una modifica dall'esito sconosciuto;
- un comando bash che può scrivere quel file, o file che non si possono identificare.

Il blocco appena scritto resta l'unico presente. Così una modifica che tocca il blocco solo in parte non può
lasciare una falsa presenza certa.

Un blocco tolto dal primo cambiamento di un file che nulla aveva ancora cambiato è testo originale, presente con
certezza dall'inizio. Negli altri casi l'intervallo di presenza è incerto.

**Vite di un blocco.** Ogni rimozione aggiunge un intervallo di presenza (una «vita») alla storia del blocco.

**Provenienza**, fissata alla prima comparsa: originale, dell'agente, incerta. Un ritorno a un blocco originale
resta «ritorno all'originale» anche dopo che l'agente l'ha riscritto. Quindi un ritorno è di tre tipi: ritorno
all'originale, versione propria, provenienza incerta.

**Già fallita.** Si prende la vita certa più recente in cui è stato eseguito almeno un comando di prova (`pytest`,
`python`, …).
- Se in quella vita un comando di prova è fallito, la versione è «già fallita», con l'ultimo fallimento.
- Se sono passati tutti, non lo è. Le vite senza prove e quelle incerte non contano.
- La riga fallita è l'ultima riga del risultato con un'espressione d'errore.
- Il fallimento è «d'infrastruttura» se la riga nomina un modulo, un comando o un file mancante, un tempo scaduto,
  un'uccisione, un permesso o una connessione. È «sconosciuto» se non c'è una riga fallita; altrimenti è «del
  programma».

**Altre proprietà dei ritorni:**
- **Progetto forse cambiato:** fra l'ultima rimozione e la riscrittura c'è una modifica di un altro percorso,
  oppure un comando bash che può scrivere, su qualunque percorso.
- **Ricorda:** le parole dell'agente al momento della riscrittura (la finestra del ragionamento, solo testo
  anteriore alla modifica) nominano, come parola intera, un errore (`FooError`, `FooException`) o un test
  (`test_foo`) della riga fallita di allora.
- **Cerchio:** la versione riscritta e quella che sostituisce erano fallite entrambe, con presenza certa e per un
  errore del programma.
  - Due errori diversi: gli insiemi dei nomi d'**errore** delle due righe (`FooError`, `FooException`; i nomi dei
    test non contano) non sono vuoti e non hanno nomi in comune.
  - Entrambi nominati: la finestra nomina almeno un nome d'errore di ciascuno.

**Altre misure:**
- tasso uniforme dell'editor: (noop + missing + multiple) / (modifiche riuscite + noop + missing + multiple), dai
  soli risultati. È l'unica misura confrontabile con Opus 4.5;
- ritorni indietro esatti (flip-flop) e di debug;
- modifiche solo di spazi;
- chiamate malformate;
- esiti sconosciuti;
- quota dei token spesi in chiamate `str_replace` fallite, dove ci sono i token. I token di una risposta sono divisi
  in parti uguali fra tutte le sue chiamate (anche quelle nello stesso messaggio); a una chiamata fallita va la sua
  parte. È un costo osservato;
- come sono stati abbinati chiamate e risultati: per identificativo, per posizione, oppure senza risultato.

**Statistica:**
- bootstrap percentile con 2.000 repliche e seme 20261009;
- si ricampionano le esecuzioni (per H2 i compiti), quindi i tentativi ripetuti nella stessa esecuzione non contano
  come campioni indipendenti;
- i rapporti sono somme su somme; le repliche con denominatore zero si scartano e si contano;
- per H3 e H4 l'unità è l'esecuzione, con l'intervallo esatto di Clopper–Pearson, valido anche con zero successi.

**Esito del compito:**
- risolto = 1, non risolto = 0;
- `no_generation` e `no_logs` restano fuori dall'analisi dell'esito;
- un'esecuzione che non compare in nessuna lista di `results.json` è contata come non risolta. Il loro numero e la
  riconciliazione degli identificativi vengono riportati.

**Regola di H3.**
- L'unità è l'esecuzione. Sono ammesse le esecuzioni con almeno un caso che ha queste tre proprietà:
  - una versione propria riscritta, con almeno una vita certa e provata;
  - nella vita certa e provata più recente, un fallimento del programma;
  - almeno un nome d'errore o di test nella riga fallita.
- Un'esecuzione è un «successo» se in almeno uno di quei casi l'agente nomina l'errore di allora.
- H3 è sostenuta se, in ogni insieme Qwen con almeno 30 esecuzioni ammesse, il limite superiore dell'intervallo
  esatto di Clopper–Pearson al 95% è sotto il 10%.
- Le versioni proprie escluse sono contate per motivo: presenza incerta, mai provata, provata e passata, fallimento
  d'infrastruttura o sconosciuto, nessun nome.
- Anche la misura per caso, con il bootstrap, viene riportata come parte descrittiva.
- **H4** usa la stessa regola sui cerchi con due errori diversi del programma (nomi d'errore disgiunti); il
  successo è un'esecuzione in cui l'agente nomina un errore di ciascuna delle due versioni.

**Stati.** Ogni ipotesi è «sostenuta», «non sostenuta» o «non valutabile». È non valutabile quando mancano dati o
intervalli, oppure, per H3 e H4, quando nessun insieme ha almeno 30 esecuzioni ammesse. Dopo aver visto i
risultati non si aggiusta niente.

## 6. Cautele e controesempi, dichiarati prima

- **Non è causa.** L'associazione con l'esito non è una causa: le esecuzioni lunghe hanno più occasioni di errore e
  spesso compiti più difficili.
- **I costi sono osservati.** Un replay dice quali richieste un controllo avrebbe intercettato, non cosa il modello
  avrebbe fatto dopo. Sottrarre i token storici non dà un risparmio.
- **«Nomina l'errore» è un indicatore stretto.** L'agente può ricordare senza nominarlo. H3 e H4 misurano
  un'omissione nel testo, non la memoria del modello.
- **Intenzione.** Dichiarazione esplicita, intenzione dedotta e caso ignoto restano distinti.
  - Le parole d'intenzione (lista di parole e giudice gemma4) non entrano nelle ipotesi.
  - La prova di sviluppo del 09/10 va confermata su casi annotati separati, con la stessa finestra anteriore alla
    modifica e senza usare l'esito successivo.

**Sei controesempi:**
1. **Ripristino voluto.** A→B→A può servire a riprodurre il difetto o a confrontare due ipotesi. L'avviso
   ricorderebbe, non vieterebbe; i conteggi dei ritorni non sono conteggi di spreco.
2. **Dipendenza corretta altrove.** Il blocco ricompare ma un altro file è cambiato: «allora il test fallì» non
   vuol dire «fallirà ancora». Per questo il progetto forse cambiato è segnato e misurato a parte.
3. **Errore d'infrastruttura.** Codice d'uscita 1 per una dipendenza assente, un tempo scaduto o un comando
   sbagliato non prova un difetto della versione. Questi casi sono separati ed esclusi da H3 e H4.
4. **Blocco fuori contesto.** Lo stesso testo in un'altra funzione o posizione dello stesso file non è per forza lo
   stesso tentativo. Non viene distinto: è un limite dichiarato.
5. **Test che modifica il progetto.** Un comando di prova può cambiare file. Se è riconosciuto come possibile
   scrittura, segna il progetto come forse cambiato; altrimenti la mutazione resta non osservata.
6. **Ciclo lungo con azioni diverse.** Riconoscere il ritorno non equivale a un beneficio. Il beneficio, gli
   avvisi impropri e i token aggiunti si misurano solo dal vivo.

## 9. Definizioni esatte

Servono per un ricalcolo indipendente. Le espressioni regolari sono in sintassi Python (`re`).

**Testi.**
- `norm(t)`: si tolgono gli a capo all'inizio e alla fine, poi gli spazi in fondo a ogni riga.
- Blocco «grande»: almeno una riga con 8 caratteri o più dopo aver tolto gli spazi ai bordi.
- `lines(t)`: l'insieme delle righe, senza spazi ai bordi, lunghe almeno 8 caratteri.
- `squash(t)`: in ogni riga gli spazi consecutivi diventano uno solo; poi si tolgono gli spazi ai bordi del testo.
- Dalle letture si tolgono i numeri di riga con `^ *\d+\t` (multilinea).

**Chiamate.**
- Si considerano solo le chiamate con argomenti JSON che sono un oggetto, nell'ordine dei messaggi; dentro un
  messaggio, nell'ordine delle chiamate.
- Il «numero di chiamata» conta queste chiamate a partire da 0 e dà l'ordine di tutto: rimozioni, prove, cambiamenti.
- Il risultato di una chiamata si cerca fra i messaggi `tool` che seguono subito il suo messaggio.
  - Se tutte le chiamate e tutti questi messaggi hanno un identificativo e gli identificativi non si ripetono, si
    abbina per identificativo.
  - Altrimenti, se i numeri coincidono, si abbina per posizione. Se gli identificativi c'erano ma si ripetevano, lo
    si conta a parte.
  - Altrimenti il risultato è vuoto.
  - Si contano le chiamate abbinate in ciascun modo.

**Ordine delle esecuzioni**, che serve al bootstrap:
- SWE-Hero: frammenti in ordine numerico, righe nell'ordine del file;
- OpenHands: cartelle dei compiti in ordine alfabetico;
- Opus: file in ordine alfabetico.

**Esito dell'editor**, controlli in quest'ordine sul risultato senza spazi iniziali:
1. Se inizia con `ERROR`, `Invalid`, `No replacement` o `Ran into`:
   - contiene `must be different` → noop;
   - contiene `did not appear verbatim` → missing;
   - contiene `[Mm]ultiple occurrences` → multiple;
   - altrimenti → other.
2. Nei primi 300 caratteri c'è `has been edited` → edited.
3. Inizia con `File created successfully` → created.
4. Inizia con `Last edit to` e nei primi 300 caratteri c'è `undone` → undo.
5. Nei primi 400 caratteri c'è ``Here's the (result of running `cat -n`|files and directories)`` → view.
6. Altrimenti → non riconosciuto.

«Riuscito» vuol dire: edited per `str_replace` e `insert`, created per `create`, view per `view`, undo per
`undo_edit`. Ogni altro esito che non sia un errore è sconosciuto.

**Comandi bash.**
- Comando di prova: `pytest|python|unittest|tox|nose|make test|npm test|go test|cargo test`.
- Fallito: se il risultato contiene `exit code (-?\d+)`, conta l'ultimo codice, ed è fallito se è diverso da 0.
  Altrimenti è fallito se contiene `Traceback|FAILED|AssertionError|Error:|error:|Exception` (FAIL).
- Riga fallita: l'ultima riga del risultato che contiene FAIL, senza spazi ai bordi, primi 120 caratteri. È vuota se
  non ce n'è una.
- Infrastruttura: la riga contiene
  `ModuleNotFoundError|No module named|command not found|[Tt]imed? ?out|Killed|Permission denied|No such file or directory|ConnectionError|MemoryError`.
- Nomi: `\b[A-Z]\w*(?:Error|Exception)\b|\btest_\w+`. Un nome è «nominato» se `\b<nome>\b` compare nella finestra.
- Lettura: il comando inizia con `cat`, `head`, `tail`, `sed -n` o `nl`. Il testo letto, senza i numeri di riga, va
  a ogni percorso assoluto nominato (`(/[\w.\-/]+\.\w+)`) e a ogni percorso noto scritto per intero nel comando,
  solo se il comando non può scrivere.
- Nel testo non trovato (asse 2) un file conta come modificato:
  - dopo un suo cambiamento riuscito o dall'esito sconosciuto;
  - dopo una scrittura bash che lo ha come bersaglio;
  - dopo una scrittura bash non identificabile, che vale per tutti i file noti.

**Scrittura da bash.**
1. Prima si tolgono le copie di descrittori e le scritture su /dev/null:
   `\d*>&\d+|&>>?\s*/dev/null|\d*>>?\s*/dev/null`.
2. Ogni bersaglio di `>>?\s*([^\s|;&<>]+)`, tolte le virgolette, viene associato al percorso noto uguale,
   o che finisce con `/` + il bersaglio senza `./` iniziale. Altrimenti resta com'è.
   - Se è vuoto o contiene `$`, un apice inverso, `*`, `?`, `{` o `[` (una variabile, una sostituzione o un modello),
     la scrittura è «non identificabile».
3. Se il comando contiene
   `sed\s+-i|\btee\b|\bmv\b|\bcp\b|git\s+(checkout|stash|apply|reset|restore|pull|merge)|\bpatch\b|open\([^)]*['\"][wa]|write_text|\bperl\s+-pi|\bblack\b|\bisort\b|\bautopep8\b`,
   sono bersagli anche i percorsi assoluti nominati e i percorsi noti nominati per intero o per nome del file.
   - Se non c'è nessun bersaglio, la scrittura è «non identificabile».
   - Dopo una scrittura non identificabile, nessun blocco è più presente con certezza e nessun blocco tolto dopo è
     più «originale».

**Ritorni.** Si elaborano le chiamate in ordine.
- Un insert, create o undo riuscito su P, un cambiamento di P dall'esito sconosciuto, o una scrittura bash con
  bersaglio P (o non identificabile): P «è stato cambiato», e nessun blocco di P (o di nessun file, per la scrittura
  non identificabile) è più presente con certezza.

Per ogni `str_replace` riuscito su P, con `old` e `new` dopo `norm`:
1. Si chiudono i «di nuovo tolto» delle versioni proprie già ritornate: il loro blocco è contenuto in `old` e non
   in `new`.
2. Se `old` è grande, si aggiunge una vita alla sua storia:
   - certa dalla chiamata in cui è stato scritto, se è il blocco presente di P;
   - certa dall'inizio (provenienza originale), se P non era mai stato cambiato e non c'era stata una scrittura non
     identificabile;
   - altrimenti incerta (provenienza incerta, se è la prima volta che il blocco compare).
   - La vita è «provata» se un comando di prova ha numero di chiamata strettamente compreso fra il suo inizio e la
     rimozione; il suo fallimento è l'ultimo comando di prova fallito in quell'intervallo.
3. Nessun blocco di P resta presente: la presenza certa finisce a ogni cambiamento del file.
4. Se `new` è grande e ha una storia in P, è un ritorno.
   - Il suo «già fallita» viene dalla vita certa e provata più recente della storia.
   - «Progetto forse cambiato» se fra l'ultima rimozione e questa chiamata c'è una scrittura bash, su qualunque
     bersaglio, o un cambiamento di un altro percorso.
5. Poi `new` diventa l'unico blocco presente di P da questa chiamata e, se non ne aveva una, riceve la provenienza
   «dell'agente».

**Finestra del ragionamento.**
- È il testo del messaggio della chiamata: il contenuto più il campo `thought` delle sue chiamate `think`.
- Prima vengono i `thought` delle chiamate precedenti della stessa risposta, cioè i messaggi segnati
  `shared_response` fino al primo della risposta, senza ripeterne il contenuto.
- Prima ancora, il testo di al massimo 3 messaggi dell'assistente precedenti, tornando indietro finché questi
  messaggi non hanno chiamate diverse da `think`.
- I pezzi si uniscono con uno spazio.

**Regole descrittive.**
- Ritorno indietro esatto (flip-flop): un `str_replace` riuscito che annulla uno precedente dello stesso file.
  - Esatto: `old` e `new` dopo `norm` uguali a `new` e `old` del precedente.
  - Dentro una finestra più larga: il `new` del precedente sta in `old`, e sostituendolo con il suo `old` si ottiene
    `new`.
  - Le righe cambiate si contano con le ripetizioni (differenza fra multinsiemi).
  - È «di debug» se ogni riga cambiata inizia con
    `print(`, `logging.`, `logger.`, `log.`, `import pdb`, `pdb.`, `breakpoint(`, `sys.stderr.write`,
    `sys.stdout.write`, `console.log`, `# DEBUG` o `traceback.print`.
- Solo spazi: `old != new` e le loro parole separate da spazi coincidono.
- Esito di una modifica nulla: «stesso punto» se un `str_replace` riuscito successivo dello stesso file ha un `old`
  che condivide una riga di `lines` con il testo della modifica nulla; «altrove» se il file è modificato dopo solo
  in altri punti; «mai più» altrimenti.

**Statistica.**
- Bootstrap: `numpy.random.default_rng(20261009).integers(0, n, size=(100, n))` per 20 blocchi, quindi 2.000
  repliche.
  - Si usa la stessa sequenza per ogni statistica dello stesso insieme.
  - Quantili: `numpy.quantile` lineare a 0,025 e 0,975.
  - H2 ricampiona i compiti comuni ai due invii con lo stesso generatore.
- Clopper–Pearson: intervallo esatto bilaterale al 95%, calcolato per bisezione (100 passi) sulla distribuzione
  binomiale.
- Mediana: quella usuale (media dei due valori centrali quando sono in numero pari).

def token_shares(msgs):
    """{message index: tokens of ONE of its calls}. A response's prompt + completion tokens are split evenly among
    all the calls of the response: the calls of its first message and of the following messages marked
    shared_response."""
    shares, group, spent = {}, [], 0

    def close():
        n = sum(len(msgs[i]["tool_calls"]) for i in group)
        for i in group:
            shares[i] = spent / n

    for i, m in enumerate(msgs):
        if m.get("role") != "assistant" or not m.get("tool_calls"):
            continue
        meta = m.get("meta") or {}
        if meta.get("shared_response") and group:
            group.append(i)
            continue
        if group:
            close()
        t = meta.get("tokens")
        group, spent = ([i], (t.get("prompt") or 0) + (t.get("completion") or 0)) if t else ([], 0)
    if group:
        close()
    return shares

            "receipt": {"events": receipt["events"], "written": receipt["written"],
                        "results_kept_raw": receipt["results_kept_raw"]},
            "editor": {k: editor[k] for k in ("edited", "noop", "missing", "multiple")}}


# ---------- statistics ----------

def resamples(n, seed=SEED):
    """Bootstrap index chunks (numpy default_rng(seed).integers): the same sequence for every statistic of a set."""
    rng = np.random.default_rng(seed)
    for start in range(0, REPS, CHUNK):
        yield rng.integers(0, n, size=(min(CHUNK, REPS - start), n))


def quantiles(vals):
    return [float(np.quantile(vals, 0.025)), float(np.quantile(vals, 0.975))] if len(vals) else None


def rate(num, den):
    """Ratio of sums over runs, with a percentile bootstrap 95% interval (runs resampled, numpy linear quantiles).
    Replicates whose denominator is zero are dropped and counted."""
    num, den = np.asarray(num, float), np.asarray(den, float)
    total = den.sum()
    out = {"num": int(num.sum()), "den": int(total), "value": float(num.sum() / total) if total else None,
           "ci95": None, "invalid_replicates": 0}
    if not total:
        return out
    vals = []
    for idx in resamples(len(num)):
        d = den[idx].sum(axis=1)
        ok = d > 0
        out["invalid_replicates"] += int((~ok).sum())
        vals.extend((num[idx].sum(axis=1)[ok] / d[ok]).tolist())
    out["ci95"] = quantiles(vals)
    return out


def binom_cdf(k, n, p):
    if p <= 0:
        return 1.0
    if p >= 1:
        return 1.0 if k >= n else 0.0
    return min(1.0, sum(math.exp(math.lgamma(n + 1) - math.lgamma(i + 1) - math.lgamma(n - i + 1)
                                 + i * math.log(p) + (n - i) * math.log(1 - p)) for i in range(k + 1)))


def clopper_pearson(k, n):
    """Exact two-sided 95% interval for k successes in n (bisection on the binomial distribution)."""
    if n == 0:
        return None
    lower, upper = 0.0, 1.0
    if k > 0:
        lo, hi = 0.0, k / n
        for _ in range(100):
            mid = (lo + hi) / 2
            lo, hi = (mid, hi) if 1 - binom_cdf(k - 1, n, mid) < 0.025 else (lo, mid)
        lower = lo
    if k < n:
        lo, hi = k / n, 1.0
        for _ in range(100):
            mid = (lo + hi) / 2
            lo, hi = (mid, hi) if binom_cdf(k, n, mid) > 0.025 else (lo, mid)
        upper = hi
    return [lower, upper]


def per_run(named, eligible):
    """Runs with at least one eligible case; success = the agent named the error in at least one of them."""
    n = sum(1 for e in eligible if e > 0)
    k = sum(1 for x, e in zip(named, eligible) if e > 0 and x > 0)
    return {"runs": n, "runs_with_a_naming": k, "value": k / n if n else None, "ci95_clopper_pearson": clopper_pearson(k, n)}


def difference(res, group):
    """Resolution rate of runs in the group minus the rate of the others, with a bootstrap 95% interval."""
    res, group = np.asarray(res, float), np.asarray(group, bool)
    out = {"value": None, "ci95": None, "n_group": int(group.sum()), "n_other": int((~group).sum()),
           "invalid_replicates": 0}
    if group.all() or not group.any():
        return out
    vals = []
    for idx in resamples(len(res)):
        r, g = res[idx], group[idx]
        ng, no = g.sum(axis=1), (~g).sum(axis=1)
        ok = (ng > 0) & (no > 0)
        out["invalid_replicates"] += int((~ok).sum())
        vals.extend(((r * g).sum(axis=1)[ok] / ng[ok] - (r * ~g).sum(axis=1)[ok] / no[ok]).tolist())
    out.update(value=float(res[group].mean() - res[~group].mean()), ci95=quantiles(vals),
               rate_group=float(res[group].mean()), rate_other=float(res[~group].mean()))
    return out


def paired_difference(a, b):
    """Failure rate per str_replace call, set a minus set b, on the tasks both sets ran (tasks resampled)."""
    ta, tb = {r["task"]: r for r in a}, {r["task"]: r for r in b}
    tasks = sorted(set(ta) & set(tb))
    fa, ca = (np.asarray([ta[t][k] for t in tasks], float) for k in ("failed", "str_replace"))
    fb, cb = (np.asarray([tb[t][k] for t in tasks], float) for k in ("failed", "str_replace"))
    out = {"tasks": len(tasks), "value": None, "ci95": None, "invalid_replicates": 0}
    if not tasks or not ca.sum() or not cb.sum():
        return out
    vals = []
    for idx in resamples(len(tasks)):
        da, db = ca[idx].sum(axis=1), cb[idx].sum(axis=1)
        ok = (da > 0) & (db > 0)
        out["invalid_replicates"] += int((~ok).sum())
        vals.extend((fa[idx].sum(axis=1)[ok] / da[ok] - fb[idx].sum(axis=1)[ok] / db[ok]).tolist())
    out.update(value=float(fa.sum() / ca.sum() - fb.sum() / cb.sum()), ci95=quantiles(vals))
    return out

def summary(recs, observations=False):
    ones = [1] * len(recs)
    s = {"runs": len(recs), "receipts_balanced": all(r["balanced"] for r in recs),
         "runs_not_balanced": sum(not r["balanced"] for r in recs)}
    totals = collections.Counter()
    aside = collections.Counter()
    for r in recs:
        totals.update(r["receipt"])
        aside.update(r["set_aside"])
    s["receipt_totals"], s["set_aside"] = dict(totals), dict(aside)
    e = [r["editor"] for r in recs]
    s["editor_failure_rate"] = rate([x["noop"] + x["missing"] + x["multiple"] for x in e],
                                    [x["edited"] + x["noop"] + x["missing"] + x["multiple"] for x in e])
    s["editor_noop_share"] = rate([x["noop"] for x in e], [x["noop"] + x["missing"] + x["multiple"] for x in e])
    s["runs_with_noop"] = rate([int(x["noop"] > 0) for x in e], ones)
    if not observations:
        failed = [r["failed"] for r in recs]
        s["failed_str_replace_per_call"] = rate(failed, [r["str_replace"] for r in recs])
        s["str_replace_unknown_outcome"] = int(sum(r["str_replace_unknown"] for r in recs))
        s["failure_type_share"] = {t: rate([r["types"][t] for r in recs], failed) for t in TYPES}
        s["noop_share_of_failures"] = s["failure_type_share"]["noop"]
        missing = [r["types"]["missing"] for r in recs]
        s["missing_class_share"] = {c: rate([r["classes"][c] for r in recs], missing) for c in CLASSES}
        s["runs_with_noop"] = rate([int(r["noops"] > 0) for r in recs], ones)
        noops = [r["noops"] for r in recs]
        s["noop_cause_share"] = {c: rate([r["causes"][c] for r in recs], noops) for c in CAUSES}
        s["noop_fate_share"] = {f: rate([r["fates"][f] for r in recs], noops) for f in FATES}
        costs = [c for r in recs for c in r["noop_costs"]]
        s["noop_calls_to_next_good_edit"] = {"n_fixed": len(costs), "n_never": int(sum(noops)) - len(costs),
                                             "median": statistics.median(costs) if costs else None}
        revisit_kinds = collections.Counter()
        for r in recs:
            revisit_kinds.update(r["revisits"])
        s["revisits"] = dict(revisit_kinds)
        s["revisits_life_uncertain"] = int(sum(r["revisits_life_uncertain"] for r in recs))
        s["runs_with_known_bad_retry"] = rate([int(r["retry_bad"] > 0) for r in recs], ones)
        s["known_bad_retry_error_named"] = rate([r["retry_bad_named"] for r in recs],
                                                [r["retry_bad_with_names"] for r in recs])
        s["known_bad_retry_error_named_per_run"] = per_run([r["retry_bad_named"] for r in recs],
                                                           [r["retry_bad_with_names"] for r in recs])
        s["known_bad_retry_error_named_same_conditions"] = rate([r["retry_bad_same_named"] for r in recs],
                                                                [r["retry_bad_same_with_names"] for r in recs])
        s["known_bad_retry_project_changed"] = rate([r["retry_bad_project_changed"] for r in recs],
                                                    [r["retry_bad"] for r in recs])
        excluded, pairing = collections.Counter(), collections.Counter()
        for r in recs:
            excluded.update(r["retry_own_excluded_from_h3"])
            pairing.update(r["pairing"])
        s["retry_own_excluded_from_h3"] = dict(excluded)
        s["retry_own_eligible_for_h3"] = int(sum(r["retry_bad_with_names"] for r in recs))
        s["pairing"] = dict(pairing)
        s["runs_with_circle"] = rate([int(r["circles"] > 0) for r in recs], ones)
        s["circles_two_errors_both_named"] = rate([r["circles_both_named"] for r in recs],
                                                  [r["circles_two_errors"] for r in recs])
        s["circles_two_errors_both_named_per_run"] = per_run([r["circles_both_named"] for r in recs],
                                                             [r["circles_two_errors"] for r in recs])
        s["runs_with_flip_flop"] = rate([int(r["flip_flop"] > 0) for r in recs], ones)
        s["whitespace_only_share"] = rate([r["whitespace_only"] for r in recs], [r["str_replace_ok"] for r in recs])
        s["counts"] = {k: int(sum(r[k] for r in recs)) for k in (
            "str_replace", "str_replace_unknown", "failed", "noops", "retry_bad", "retry_bad_infra_or_unknown",
            "circles", "circles_two_errors", "flip_flop", "debug_reverts", "undo", "malformed")}
        versions = collections.Counter()
        for r in recs:
            versions.update(r["framework_versions"])
        s["framework_versions"] = dict(versions)
        if any(r["tokens_all"] for r in recs):
            s["token_share_in_failed_str_replace_calls"] = rate([r["tokens_failed_str_replace"] for r in recs],
                                                                [r["tokens_all"] for r in recs])
    graded = [r for r in recs if r["outcome"] in ("resolved", "unresolved")]
    if graded:
        res = [int(r["outcome"] == "resolved") for r in graded]
        noop = [(r["noops"] if "noops" in r else r["editor"]["noop"]) > 0 for r in graded]
        s["outcome"] = {"graded_runs": len(graded), "resolved_rate": float(np.mean(res)),
                        "not_graded": len(recs) - len(graded), "with_vs_without_noop": difference(res, noop)}
        if not observations:
            s["outcome"]["with_vs_without_circle"] = difference(res, [r["circles"] > 0 for r in graded])
    return s


def reconcile(recs, outcomes):
    ids = [r["id"] for r in recs]
    return {"runs": len(ids), "unique_ids": len(set(ids)), "ids_not_like_swebench": sum(not SWEBENCH_ID.match(i) for i in ids),
            "listed_in_results": len(outcomes), "listed_without_a_run": len(set(outcomes) - set(ids)),
            "runs_not_listed_counted_unresolved": len(set(ids) - set(outcomes))}


def structural_problems(sets_recs, sets_outcomes, conflicts=None):
    """Checks that must pass before the hypotheses are evaluated."""
    problems = [f"{k}: {len(v)} ids in more than one list of results.json" for k, v in (conflicts or {}).items() if v]
    for name, recs in sets_recs.items():
        if name in EXPECTED_RUNS and len(recs) != EXPECTED_RUNS[name]:
            problems.append(f"{name}: {len(recs)} runs instead of {EXPECTED_RUNS[name]}")
        bad = sum(not r["balanced"] for r in recs)
        if bad:
            problems.append(f"{name}: {bad} receipts not balanced")
        differing = sum(r["receipt"].get("edits_differing", 0) for r in recs)
        if differing:
            problems.append(f"{name}: {differing} str_replace calls differ from the recorded action")
        if len({r["id"] for r in recs}) != len(recs):
            problems.append(f"{name}: duplicate run ids")
    small, large = "openhands_qwen3_coder_30b", "openhands_qwen3_coder_480b"
    if small in sets_recs and large in sets_recs:
        ids = {k: {r["id"] for r in sets_recs[k]} for k in sets_recs if sets_outcomes.get(k) is not None}
        universe = ids[small] | ids[large]
        if ids[small] != ids[large]:
            problems.append("the 30B and 480B submissions do not cover the same tasks")
        for k in ids:
            if ids[k] - universe:
                problems.append(f"{k}: {len(ids[k] - universe)} run ids outside the shared task list")
            if set(sets_outcomes[k]) - universe:
                problems.append(f"{k}: {len(set(sets_outcomes[k]) - universe)} ids in results.json outside the "
                                "shared task list")
    return problems


def status(evaluable, supported):
    return "not_evaluable" if not evaluable else "supported" if supported else "not_supported"


def hypotheses(sets, recs, dev):
    h = {}
    q = [sets[k] for k in QWEN_SETS]
    h1 = []
    for s in q:
        shares = {t: s["failure_type_share"][t]["value"] for t in TYPES}
        h1.append(s["failure_type_share"]["noop"]["den"] > 0 and
                  all(shares["noop"] > shares[t] for t in TYPES if t != "noop"))
    h["H1"] = {"rule": "in each Qwen set, failures > 0 and the noop share strictly above every other type",
               "per_set": dict(zip(QWEN_SETS, h1)),
               "status": status(all(s["failure_type_share"]["noop"]["den"] > 0 for s in q), all(h1))}
    d = paired_difference(recs["openhands_qwen3_coder_30b"], recs["openhands_qwen3_coder_480b"])
    h["H2"] = {"rule": "failed str_replace per call, 30B minus 480B on the shared tasks (tasks resampled): "
                       "95% interval above 0", "difference": d,
               "status": status(d["ci95"] is not None, d["ci95"] is not None and d["ci95"][0] > 0)}
    for key, field in (("H3", "known_bad_retry_error_named_per_run"), ("H4", "circles_two_errors_both_named_per_run")):
        per_set = {k: sets[k][field] for k in QWEN_SETS}
        evaluable = {k: v for k, v in per_set.items() if v["runs"] >= 30}
        h[key] = {"rule": f"{field}: in every Qwen set with at least 30 eligible runs, the Clopper-Pearson 95% upper "
                          "bound is below 0.10 (at least one such set)", "evaluable_sets": sorted(evaluable),
                  "status": status(bool(evaluable), all(v["ci95_clopper_pearson"][1] < 0.10 for v in evaluable.values()))}
    h5 = {k: sets[k].get("outcome", {}).get("with_vs_without_noop", {}) for k in QWEN_SETS[1:]}
    h["H5"] = {"rule": "resolution rate with a no-op minus without, 95% interval below 0, in both OpenHands Qwen sets",
               "status": status(all(v.get("ci95") for v in h5.values()),
                                all(v.get("ci95") and v["ci95"][1] < 0 for v in h5.values()))}
    r2e = sets["swehero_heldout"]["by_collection"].get("R2E-Gym/R2E-Gym-Subset")
    ok = bool(r2e) and all(r2e[k]["ci95"] is not None and dev[k]["value"] is not None for k in REPLICATED)
    h["H6"] = {"rule": "dev point estimate inside the 95% interval of the held-out R2E-Gym runs, for " + ", ".join(REPLICATED),
               "dev": {k: dev[k]["value"] for k in REPLICATED},
               "held_out_r2e": {k: (r2e[k]["value"], r2e[k]["ci95"]) if r2e else None for k in REPLICATED},
               "status": status(ok, ok and all(r2e[k]["ci95"][0] <= dev[k]["value"] <= r2e[k]["ci95"][1]
                                               for k in REPLICATED))}
    return h

def inputs(part):
    files = []
    for name, kind, where in PARTS[part]:
        if kind == "swehero":
            files += where
        else:
            trajs, results = where
            files += sorted(glob.glob(os.path.join(trajs, "**", "*.json"), recursive=True)) + [results]
    return files


def sha(path):
    h = hashlib.sha256()
    with open(path, "rb") as fh:
        for block in iter(lambda: fh.read(1 << 20), b""):
            h.update(block)
    return h.hexdigest()


def finite(x):
    if isinstance(x, float) and not math.isfinite(x):
        return None
    if isinstance(x, dict):
        return {k: finite(v) for k, v in x.items()}
    if isinstance(x, (list, tuple)):
        return [finite(v) for v in x]
    return x


def read(kind, where):
    """(records, outcomes, conflicting ids in results.json)."""
    if kind == "swehero":
        return [record(run) for run in formati.swehero(where)], None, []
    trajs, results = where
    outcomes, conflicts = formati.outcomes_and_conflicts(results)
    if kind == "openhands":
        return [record(run) for run in formati.openhands_events(trajs, outcomes)], outcomes, conflicts
    return [record_observations(run) for run in formati.observation_logs(trajs, outcomes)], outcomes, conflicts


def main():
    part = sys.argv[1] if len(sys.argv) > 1 else ""
    if part not in PARTS:
        sys.exit("usage: python -I misura.py dev|heldout")
    os.makedirs(OUT_DIR, exist_ok=True)
    started, out_path = (os.path.join(OUT_DIR, f"misura_{part}.{x}") for x in ("started", "json"))
    if os.path.exists(started) or os.path.exists(out_path):
        sys.exit(f"misura_{part} was already started: a new run needs a declared deviation")
    code = {f: sha(os.path.join(HERE, f)) for f in ("formati.py", "rilevatori.py", "misura.py")}
    dev_path = os.path.join(OUT_DIR, "misura_dev.json")
    marker = {"part": part, "started": datetime.datetime.now().isoformat(timespec="seconds"), "code_sha256": code}
    with open(started, "x", encoding="utf-8") as fh:
        json.dump(marker, fh, indent=1)
    print("started", started, flush=True)
    files = ([dev_path] if part == "heldout" else []) + inputs(part)
    manifest = [{"path": os.path.relpath(f, ROOT), "bytes": os.path.getsize(f), "sha256": sha(f)} for f in files]
    with open(os.path.join(OUT_DIR, f"misura_{part}.inputs.json"), "x", encoding="utf-8") as fh:
        json.dump(manifest, fh, indent=1)
    dev = None
    if part == "heldout":
        with open(dev_path, encoding="utf-8") as fh:
            dev = json.load(fh)["sets"]["swehero_dev"]
    sets, recs, all_outcomes, conflicts = {}, {}, {}, {}
    for name, kind, where in PARTS[part]:
        recs[name], outcomes, conflicts[name] = read(kind, where)
        all_outcomes[name] = outcomes
        sets[name] = summary(recs[name], observations=(kind == "observations"))
        if outcomes is not None:
            sets[name]["reconciliation"] = reconcile(recs[name], outcomes)
        if kind == "swehero":
            groups = collections.defaultdict(list)
            for r in recs[name]:
                groups[r["collection"]].append(r)
            sets[name]["by_collection"] = {c: summary(g) for c, g in sorted(groups.items())}
        print(name, sets[name]["runs"], "runs", flush=True)
    problems = structural_problems(recs, all_outcomes, conflicts)
    result = {"part": part, "written": datetime.datetime.now().isoformat(timespec="seconds"),
              "bootstrap": {"replicates": REPS, "seed": SEED, "unit": "run (task for H2)"},
              "code_sha256": code, "structural_problems": problems, "sets": sets}
    if part == "heldout":
        result["hypotheses"] = (hypotheses(sets, recs, dev) if not problems else
                                "not evaluated: structural checks failed")
    with open(out_path, "x", encoding="utf-8") as fh:
        json.dump(finite(result), fh, indent=1, allow_nan=False)
    print("written", out_path, "| structural problems:", problems or "none")


if __name__ == "__main__":
    main()

===== rilevatori.py =====
"""Detectors of failed and wasted edits in coding-agent trajectories, version 3 (read only, nothing is executed).

Every detector reads one trajectory in the common message shape of formati.py and only looks at tool calls and
their results. A path P is a file as the agent names it. Order is the call number: calls with JSON-object arguments
counted from 0 in message order and, within a message, in call order ("step" is the message index, kept for
reading the context). Costs are counted in calls.

Results (pair()). When every call and every following tool message has an id and the ids are unique, results are
paired by id; otherwise the k-th tool message goes with the k-th call when their numbers match; otherwise every
result is missing. An editor result is "ok" only when the editor's success message matches the command (edited for
str_replace and insert, created, view, undone); the errors are noop ("must be different"), missing ("did not
appear verbatim"), multiple ("Multiple occurrences") and other; anything else, including a missing result, is
"unknown" and is counted apart, never as a success.

1. edit_failures: every str_replace that is not ok (an unknown outcome is listed with error "unknown"). For a
   missing old_str S, the evidence on what the agent had seen of P: texts(P) are the earlier successful views of P
   (line numbers removed), the snippets shown after its edits, bash reads of P (cat, head, tail, sed -n, nl with P
   named in the command, also when P was never seen before, unless the command may also write; line numbers
   removed) and every text the agent wrote into P. P counts as modified by its own edits, by changes of P with an
   unknown outcome, by bash commands that may write it (write_targets), and by bash writes that cannot be
   identified (all known paths).
     stale              S is in an earlier text of P, and P was modified after the last text containing S;
     copy_error         S is in no earlier text, but it is once the whitespace of every line is normalized;
     seen_not_modified  S is in an earlier text and P was not modified since;
     never_seen         none of the above ("not observed in the log", which does not mean invented).
2. noops: every no-op str_replace on P with text S, by cause, checked in this order
     already_applied  S equals the new_str of an earlier successful str_replace of P;
     repeat_attempt   the same (P, S) no-op was attempted before;
     after_failure    the last bash command before it had failed (failed());
     other.
   Cost: tool calls after the no-op up to the next successful str_replace, insert or create of P, that call
   included (None if there is none). Fate: same_spot if a later successful str_replace of P has an old_str sharing a
   line of at least 8 characters with S, elsewhere if P is edited later only at other spots, never otherwise.
3. reverts: a successful str_replace that undoes an earlier successful one of P, exactly or inside a larger
   window; "debug" when every changed line is a print, log or debugger line, else "flip_flop". Also counted:
   successful str_replace calls, the ones that only change whitespace, and undo_edit calls.
4. revisits (version memory). A block is the text of a successful str_replace's old_str or new_str after norm(),
   with a line of at least 8 characters; its identity is that text within one path.
   - Presence is certain (prudent rule) from the call at which the agent wrote the block with a successful
     str_replace until the next change of P of any kind: any other successful str_replace, insert, create or
     undo_edit of P, a change of P with an unknown outcome, a bash command that may write P, or a bash write that
     cannot be identified. A block removed by the first change of a path that nothing had changed before is
     original text, present with certainty since the start. Any other removed block has an uncertain interval.
   - Provenance is fixed at the first sighting: original, agent, or uncertain. A later return to an original block
     stays back_to_original even after the agent wrote it again.
   - Every removal of a block adds one presence interval (a "life") to its history.
   - A successful edit whose new block equals a block removed earlier from the same path is a revisit:
     back_to_original, retry_own or uncertain_provenance.
   - known_bad: take the most recent certain life in which a test-like command (TESTLIKE) ran; known_bad is the
     last failing one of those commands (failed()), or None if they all passed. Its failing line is the last result
     line matching FAIL, cut to 120 characters. The failure is "infra" if that line matches INFRA, "unknown" if the
     line is empty, else "application".
   - replaced_bad: the same for the block that the revisit removes. project_changed: between the last removal of
     the block and the revisit there was a bash command that may write (any target), or a change of another path.
   - again (retry_own): calls until a later successful str_replace of P removes the block again.
5. intent: the reasoning window of a call (window()) and whether it declares a deliberate return (DECLARED).
6. remembers: for a revisit with a known_bad line, whether the window names, as a whole word, an error
   (FooError, FooException) or a test (test_foo) of that line. None when there is no such name.
"""

import collections
import json
import re

from formati import editor_outcome

FAIL = re.compile(r"Traceback|FAILED|AssertionError|Error:|error:|Exception")
LINE_NO = re.compile(r"^ *\d+\t", re.M)
OTHER_WRITES = re.compile(r"sed\s+-i|\btee\b|\bmv\b|\bcp\b|git\s+(checkout|stash|apply|reset|restore|pull|merge)|"
                          r"\bpatch\b|open\([^)]*['\"][wa]|write_text|\bperl\s+-pi|\bblack\b|\bisort\b|\bautopep8\b")
FD_DUP = re.compile(r"\d*>&\d+|&>>?\s*/dev/null|\d*>>?\s*/dev/null")
READS = re.compile(r"^\s*(cat|head|tail|sed\s+-n|nl)\b")
PATHS = re.compile(r"(/[\w.\-/]+\.\w+)")
REDIRECT = re.compile(r">>?\s*([^\s|;&<>]+)")
DEBUG = re.compile(r"^\s*(print\(|logging\.|logger\.|log\.|import pdb|pdb\.|breakpoint\(|sys\.std(err|out)\.write"
                   r"|console\.log|#\s*DEBUG|traceback\.print)")
TESTLIKE = re.compile(r"pytest|python|unittest|tox|nose|make test|npm test|go test|cargo test")
EXIT = re.compile(r"exit code (-?\d+)")
DECLARED = re.compile(
    r"\brevert|\bundo|\bundid|\brestor|roll(ing|ed)? ?back|go(ing)? back|went back|\bback to (the |my |our )?"
    r"(original|previous|old|earlier|initial|prior)|(original|previous|old|earlier|initial|prior) (code|version|"
    r"implementation|approach|fix|logic|behaviou?r|state|change|condition|line)|(put|change|switch|move|add|bring)"
    r"(ing|ed)? (it |this |that |them |these |those )?back|re-?appl|temporar", re.I)
ERRORS = {"noop": "noop", "missing": "missing", "multiple": "multiple", "other_error": "other"}
OK_RESULT = {"str_replace": "edited", "insert": "edited", "create": "created", "view": "view", "undo_edit": "undo"}
ERROR_NAMES = re.compile(r"\b[A-Z]\w*(?:Error|Exception)\b|\btest_\w+")
INFRA = re.compile(r"ModuleNotFoundError|No module named|command not found|[Tt]imed? ?out|Killed|Permission denied|"
                   r"No such file or directory|ConnectionError|MemoryError")
CHANGES = ("create", "insert", "str_replace", "undo_edit")


def pair(messages, i):
    """The results of the calls of message i, in call order, and how they were paired: "id" when every call and
    every following tool message has an id and the ids are unique, else "position" when the numbers match, else
    "none" (every result missing)."""
    tcs = messages[i].get("tool_calls") or []
    results, j = [], i + 1
    while j < len(messages) and messages[j].get("role") == "tool":
        results.append(messages[j])
        j += 1
    result_ids, call_ids = [r.get("tool_call_id") for r in results], [c.get("id") for c in tcs]
    with_ids = all(result_ids) and all(call_ids)
    if with_ids and len(set(result_ids)) == len(results) and len(set(call_ids)) == len(tcs):
        by_id = dict(zip(result_ids, results))
        return [by_id.get(c) for c in call_ids], "id"
    if len(results) == len(tcs):
        return results, "position_after_duplicate_ids" if with_ids else "position"
    return [None] * len(tcs), "none"


def calls(messages):
    """(index, tool name, arguments, result text) for every tool call whose arguments are a JSON object, in message
    order and, within a message, in call order. The result text is "" when no result can be paired with the call."""
    for i, m in enumerate(messages):
        tcs = m.get("tool_calls") or []
        if not tcs:
            continue
        paired, _ = pair(messages, i)
        for c, r in zip(tcs, paired):
            try:
                args = json.loads(c["function"]["arguments"])
            except (ValueError, TypeError):
                continue
            if not isinstance(args, dict):
                continue
            obs = (r or {}).get("content")
            yield i, c["function"]["name"], args, obs if isinstance(obs, str) else ("" if obs is None else json.dumps(obs))


def pairing_counts(messages):
    """How the calls of a trajectory were paired with their results: {"id": n, "position": n, "none": n}."""
    out = collections.Counter()
    for i, m in enumerate(messages):
        if m.get("tool_calls"):
            out[pair(messages, i)[1]] += len(m["tool_calls"])
    return dict(out)


def result_kind(cmd, obs):
    """ok, noop, missing, multiple, other or unknown, for an editor call with this command."""
    e = editor_outcome(obs or "")
    if e in ERRORS:
        return ERRORS[e]
    return "ok" if OK_RESULT.get(cmd) == e else "unknown"


def error_type(obs):
    """noop, missing, multiple or other for an editor error message, else None (also for unknown results)."""
    return ERRORS.get(editor_outcome(obs or ""))


def squash(text):
    return "\n".join(" ".join(line.split()) for line in text.splitlines()).strip()


def norm(text):
    return "\n".join(x.rstrip() for x in text.strip("\n").splitlines())


def lines(text):
    return {x.strip() for x in text.splitlines() if len(x.strip()) >= 8}


def big(text):
    return any(len(x.strip()) >= 8 for x in text.splitlines())


def changed_lines(a, b):
    """The lines of a and b that the other one lacks, counting repeated lines (multiset difference)."""
    ca, cb = collections.Counter(a.splitlines()), collections.Counter(b.splitlines())
    return list((ca - cb).elements()) + list((cb - ca).elements())


def failed(obs):
    codes = EXIT.findall(obs or "")
    return codes[-1] != "0" if codes else bool(FAIL.search(obs or ""))


def names_in(line):
    return set(ERROR_NAMES.findall(line or ""))


def error_names_in(line):
    """Only the error names (FooError, FooException) of a line, without test names."""
    return {x for x in names_in(line) if not x.startswith("test_")}


def mentions(text, name):
    return re.search(r"\b" + re.escape(name) + r"\b", text or "") is not None


def write_targets(command, known):
    """Paths that a bash command may write, or None when it may write files that cannot be identified.
    Descriptor copies (2>&1) and writes to /dev/null are not writes. A redirect writes its target (quotes removed),
    matched to a known path when possible; a target with a variable, a substitution or a pattern ($ ` * ? { [) cannot
    be identified. Other writing commands (OTHER_WRITES: sed -i, tee, mv, cp, git checkout, patch, open(..., 'w'),
    ...) may write any absolute path they name and any known path named in full or by file name."""
    clean = FD_DUP.sub(" ", command)
    redirects = [t.strip("'\"") for t in REDIRECT.findall(clean)]
    other = OTHER_WRITES.search(clean)
    targets = set()
    for t in redirects:
        if not t or any(ch in t for ch in "$`*?{["):
            return None
        targets |= {p for p in known if p == t or p.endswith("/" + t.lstrip("./"))} or {t}
    if other:
        named = set(PATHS.findall(clean)) | {p for p in known if p and (p in clean or p.rsplit("/", 1)[-1] in clean)}
        if not named:
            return None
        targets |= named
    return targets


def edit_failures(messages):
    texts = collections.defaultdict(list)       # path -> [(call number, text)]
    modified = collections.defaultdict(list)    # path -> [call number]
    events = []
    for k, (i, name, args, obs) in enumerate(calls(messages)):
        if name == "str_replace_editor":
            cmd, p = args.get("command"), args.get("path")
            kind = result_kind(cmd, obs)
            if kind == "ok":
                if cmd == "view":
                    texts[p].append((k, LINE_NO.sub("", obs)))
                elif cmd == "create":
                    texts[p].append((k, args.get("file_text") or ""))
                    modified[p].append(k)
                elif cmd == "str_replace":
                    texts[p] += [(k, args.get("new_str") or ""), (k, LINE_NO.sub("", obs))]
                    modified[p].append(k)
                elif cmd in ("insert", "undo_edit"):
                    texts[p].append((k, (args.get("new_str") or "") + "\n" + LINE_NO.sub("", obs)))
                    modified[p].append(k)
            elif cmd in CHANGES and kind == "unknown":
                modified[p].append(k)
                if cmd == "str_replace":
                    events.append({"step": i, "call": k, "path": p, "error": "unknown"})
            elif cmd == "str_replace":
                s = args.get("old_str") or ""
                ev = {"step": i, "call": k, "path": p, "error": kind}
                if kind == "missing":
                    hits = [t for t, x in texts[p] if s and s in x]
                    if hits:
                        ev["kind"] = "stale" if any(t > max(hits) for t in modified[p]) else "seen_not_modified"
                    elif s and any(squash(s) in squash(x) for _, x in texts[p]):
                        ev["kind"] = "copy_error"
                    else:
                        ev["kind"] = "never_seen"
                events.append(ev)
        elif name == "execute_bash":
            command = args.get("command") or ""
            targets = write_targets(command, list(texts))
            for p in (list(texts) if targets is None else targets):
                modified[p].append(k)
            if targets == set() and READS.search(command):
                for p in set(PATHS.findall(command)) | {q for q in texts if q and q in command}:
                    texts[p].append((k, LINE_NO.sub("", obs)))
    return events


def noops(messages):
    applied = collections.defaultdict(set)      # path -> new_str of successful str_replace
    good = collections.defaultdict(list)        # path -> [(call number, old_str or None)] of successful edits
    tried, found = set(), []
    last_failed = False
    for k, (i, name, a, obs) in enumerate(calls(messages)):
        if name == "str_replace_editor":
            cmd, p = a.get("command"), a.get("path")
            kind = result_kind(cmd, obs)
            old, new = a.get("old_str") or "", a.get("new_str") or ""
            if cmd == "str_replace" and kind == "noop":
                cause = ("already_applied" if old in applied[p] else "repeat_attempt" if (p, old) in tried
                         else "after_failure" if last_failed else "other")
                tried.add((p, old))
                found.append({"step": i, "call": k, "path": p, "text": old, "kind": cause})
            elif cmd == "str_replace" and kind == "ok":
                applied[p].add(new)
                good[p].append((k, old))
            elif cmd in ("insert", "create") and kind == "ok":
                good[p].append((k, None))
        if name == "execute_bash":
            last_failed = failed(obs)
    for f in found:
        later = [(k, o) for k, o in good[f["path"]] if k > f["call"]]
        f["cost"] = later[0][0] - f["call"] if later else None
        f["fate"] = ("same_spot" if any(o is not None and lines(o) & lines(f["text"]) for _, o in later)
                     else "elsewhere" if later else "never")
    return found


def reverts(messages):
    done = collections.defaultdict(list)        # path -> [(index, old, new)] of successful str_replace
    out = {"reverts": [], "str_replace_ok": 0, "whitespace_only": 0, "undo": 0}
    for i, name, a, obs in calls(messages):
        if name != "str_replace_editor":
            continue
        cmd, p = a.get("command"), a.get("path")
        old, new = a.get("old_str") or "", a.get("new_str") or ""
        if cmd == "undo_edit":
            out["undo"] += 1
        if cmd != "str_replace" or result_kind(cmd, obs) != "ok":
            continue
        out["str_replace_ok"] += 1
        out["whitespace_only"] += old != new and old.split() == new.split()
        for j, o1, n1 in done[p]:
            exact = norm(old) == norm(n1) and norm(new) == norm(o1)
            window = bool(n1) and n1 in old and old.replace(n1, o1, 1) == new
            if exact or window:
                ch = changed_lines(o1, n1)
                kind = "debug" if ch and all(DEBUG.match(x) for x in ch) else "flip_flop"
                out["reverts"].append({"step": i, "path": p, "kind": kind, "turns": (i - j) // 2})
                break
        done[p].append((i, old, new))
    return out


def failure_kind(bad):
    if bad is None:
        return None
    return "unknown" if not bad[2] else "infra" if INFRA.search(bad[2]) else "application"


def last_tested(history):
    """The failing test of the most recent certain life in which a test-like command ran (None if it passed, or if
    no certain life was tested)."""
    tested = [x for x in history if x["certain"] and x["tested"]]
    return tested[-1]["bad"] if tested else None


def revisits(messages):
    present = collections.defaultdict(dict)       # path -> block -> call number from which its presence is certain
    origin = collections.defaultdict(dict)        # path -> block -> original | agent | uncertain (first sighting)
    lives = collections.defaultdict(dict)         # path -> block -> [presence intervals, once removed]
    touched = set()                               # paths that something may have changed
    tests, changes, events = [], [], []           # tests: (call, failed, line); changes: (call, path, source)
    unidentified_write = False
    for k, (i, name, a, obs) in enumerate(calls(messages)):
        if name == "execute_bash":
            command = str(a.get("command", ""))
            if TESTLIKE.search(command):
                f = failed(obs)
                line = next((x.strip() for x in obs.splitlines()[::-1] if FAIL.search(x)), "") if f else ""
                tests.append((k, f, line[:120]))
            targets = write_targets(command, list(touched | set(present) | set(lives)))
            if targets is None:
                unidentified_write = True
                present.clear()
            for t in targets or ():
                present[t].clear()
                touched.add(t)
            if targets is None or targets:
                changes.append((k, None, "bash"))
            continue
        if name != "str_replace_editor":
            continue
        cmd, p = a.get("command"), a.get("path")
        kind = result_kind(cmd, obs)
        if (cmd in CHANGES and kind == "unknown") or (cmd in CHANGES and cmd != "str_replace" and kind == "ok"):
            present[p].clear()
            touched.add(p)
            changes.append((k, p, "editor"))
            continue
        if kind != "ok" or cmd != "str_replace":
            continue
        old, new = norm(a.get("old_str") or ""), norm(a.get("new_str") or "")
        for e in events:
            if e["kind"] == "retry_own" and e["path"] == p and e["again"] is None and e["block"] in old \
                    and e["block"] not in new:
                e["again"] = k - e["call"]
        if big(old):
            if old in present[p]:
                start = present[p][old]
            elif p not in touched and not unidentified_write:
                start = -1
                origin[p].setdefault(old, "original")
            else:
                start = None
                origin[p].setdefault(old, "uncertain")
            during = [t for t in tests if start is not None and start < t[0] < k]
            lives[p].setdefault(old, []).append({
                "bad": next((t for t in reversed(during) if t[1]), None) if start is not None else None,
                "tested": bool(during), "removed_at": i, "removed_call": k, "certain": start is not None})
        present[p].clear()
        touched.add(p)
        changes.append((k, p, "editor"))
        if big(new):
            if new in lives[p]:
                history = lives[p][new]
                last = history[-1]
                bad = last_tested(history)
                events.append({
                    "step": i, "call": k, "path": p, "block": new, "removed": old,
                    "removed_at": last["removed_at"], "removed_call": last["removed_call"],
                    "kind": {"original": "back_to_original", "agent": "retry_own"}.get(origin[p].get(new),
                                                                                     "uncertain_provenance"),
                    "life_certain": any(x["certain"] for x in history), "known_bad": bad,
                    "tested": any(x["certain"] and x["tested"] for x in history),
                    "known_bad_kind": failure_kind(bad),
                    "replaced_bad": last_tested(lives[p][old]) if big(old) else None,
                    "project_changed": any(last["removed_call"] < s < k and (src == "bash" or q != p)
                                           for s, q, src in changes),
                    "again": None})
            origin[p].setdefault(new, "agent")
            present[p][new] = k
    return events


def thoughts_of(m):
    out = []
    for c in m.get("tool_calls") or []:
        if c["function"]["name"] == "think":
            try:
                out.append(json.loads(c["function"]["arguments"]).get("thought") or "")
            except (ValueError, TypeError, AttributeError):
                pass
    return " ".join(x for x in out if x)


def text_of(m):
    content = m.get("content") if isinstance(m.get("content"), str) else ""
    return " ".join(x for x in (content, thoughts_of(m)) if x)


def window(messages, i):
    """The reasoning before call message i: the thoughts of the earlier calls of the same response (messages marked
    shared_response, back to the response's first message), the text of message i, and the text of at most 3 earlier
    assistant messages that only hold think calls."""
    first = i
    while (messages[first].get("meta") or {}).get("shared_response"):
        j = first - 1
        while j >= 0 and messages[j].get("role") != "assistant":
            j -= 1
        if j < 0:
            break
        first = j
    same = [thoughts_of(messages[j]) for j in range(first, i) if messages[j].get("role") == "assistant"]
    parts, seen = [x for x in same if x] + [text_of(messages[i])], 0
    for j in range(first - 1, -1, -1):
        m = messages[j]
        if m.get("role") != "assistant":
            continue
        if {c["function"]["name"] for c in m.get("tool_calls") or []} - {"think"} or seen >= 3:
            break
        parts.insert(0, text_of(m))
        seen += 1
    return " ".join(p for p in parts if p).strip()


def intent(messages, i):
    """'silent' (no text), 'declared' (a deliberate return is stated) or 'undeclared'."""
    w = window(messages, i)
    return "silent" if not w else "declared" if DECLARED.search(w) else "undeclared"


def remembers(messages, event):
    """For a revisit with a known_bad line: does the reasoning window name, as a whole word, an error or a test of
    that line? None when there was no failure, or when the failing line names nothing."""
    if not event.get("known_bad"):
        return None
    found = names_in(event["known_bad"][2])
    if not found:
        return None
    w = window(messages, event["step"])
    return any(mentions(w, n) for n in found)

===== formati.py =====
"""Translate coding-agent trajectories ("diaries") from three public formats into one common shape.

Read only: nothing in a trajectory is executed. The shape is described in FORMATO_COMUNE.md. In short, one run is
    {"id", "task", "collection", "source", "model", "outcome", "patch", "messages", "observations", "receipt"}
and its messages are the ones of the SWE-Hero dataset, each tool result right after the call that asked for it:
    {"role": "assistant", "content": str, "tool_calls": [{"id": str, "function": {"name": str, "arguments": str}}]}
    {"role": "tool", "content": str, "tool_call_id": str}
A message may carry margin notes in "meta" when its source keeps them: "time" (ISO timestamp), "tokens" (prompt and
completion tokens of the model response, on its first call only), "shared_response" (true on the later calls of a
response with several calls, which repeat the response's text), "file_before" and "file_after" (the whole file
around a successful edit). Every run comes with a receipt that accounts for each event of the source: written into
a message, or set aside with its reason.

Sources:
- SWE-Hero (NVIDIA, parquet shards): already in this shape; the cover keeps the final patch.
- OpenHands event lists (SWE-bench Verified submissions, `<set>/<instance>/trajectory.json`): rebuilt from the
  tool-call metadata of each result, which keeps the model's raw call; each str_replace call is checked against
  the action that the agent framework recorded. A command result gets back the exit-code line that the model saw,
  which the event list keeps apart. An error raised before any tool ran (for example a call without a required
  argument) has no call to attach to, so it is kept as {"role": "error", "content": ...}.
- Observation-only logs (the Claude Opus 4.5 submission, `<set>/<instance>.json`): the actions were not saved
  ("Action: unknown"), so only tool results can be read, as (tool, text) pairs; `editor_outcome` sorts them.
"""

import ast
import collections
import glob
import json
import os
import re

# Action arguments kept when a call has to be rebuilt from the action (the model's raw call is missing).
KEEP = ("command", "path", "old_str", "new_str", "file_text", "insert_line", "view_range", "is_input")
TOOL_PREFIX = re.compile(r"\[(\w+)\] (.*)", re.S)
VIEW = re.compile(r"Here's the (result of running `cat -n`|files and directories)")


def new_receipt():
    return {"events": 0, "written": 0, "set_aside": collections.Counter(), "calls": 0, "calls_rebuilt": 0,
            "edits_checked": 0, "edits_differing": 0, "exit_lines_restored": 0, "malformed_calls": 0,
            "results_kept_raw": 0, "models": collections.Counter(), "framework_versions": collections.Counter()}


def balanced(receipt):
    """True when every event of the source is either written or set aside."""
    return receipt["written"] + sum(receipt["set_aside"].values()) == receipt["events"]


def load_outcomes(path):
    """{instance id: "resolved" | "no_generation" | "no_logs"} from a SWE-bench results.json."""
    return outcomes_and_conflicts(path)[0]


def outcomes_and_conflicts(path):
    """The outcome of every listed instance, and the ids that appear in more than one list (a conflict that the
    caller must report; the last list read, "resolved", wins)."""
    with open(path, encoding="utf-8") as fh:
        lists = json.load(fh)
    out, conflicts = {}, set()
    for label in ("no_generation", "no_logs", "resolved"):
        for instance in lists.get(label) or []:
            if instance in out and out[instance] != label:
                conflicts.add(instance)
            out[instance] = label
    return out, sorted(conflicts)


def outcome(outcomes, instance):
    """The task outcome of a run; an instance in no list is unresolved; None without a results file."""
    return None if outcomes is None else outcomes.get(instance, "unresolved")


def raw_call(tcm):
    """(response key, response text, tool name, raw JSON arguments) of the call named in the tool-call metadata.
    The response key is the response id, or, when it is missing, the tuple of the response's call ids, so that the
    calls of one response share it."""
    resp = tcm.get("model_response") or {}
    choices = resp.get("choices") or [{}]
    msg = (choices[0] or {}).get("message") or {}
    calls = msg.get("tool_calls") or []
    key = resp.get("id") or (("calls",) + tuple(c.get("id") for c in calls) if calls else None)
    for c in calls:
        if c.get("id") == tcm.get("tool_call_id"):
            return key, msg.get("content"), c["function"]["name"], c["function"]["arguments"]
    return key, msg.get("content"), None, None


def rebuilt_arguments(action):
    args = {k: v for k, v in (action.get("args") or {}).items() if k in KEEP}
    if action.get("action") == "read":
        args.setdefault("command", "view")
    return json.dumps(args)


def check_edit(arguments, action, receipt):
    """Count a str_replace call whose raw arguments disagree with the action the framework recorded."""
    try:
        a = json.loads(arguments)
    except (ValueError, TypeError):
        return
    if not isinstance(a, dict) or a.get("command") != "str_replace":
        return
    receipt["edits_checked"] += 1
    recorded = action.get("args") or {}
    receipt["edits_differing"] += action.get("action") != "edit" or \
        any(a.get(k) != recorded.get(k) for k in ("path", "old_str", "new_str"))


def with_meta(message, **notes):
    notes = {k: v for k, v in notes.items() if v is not None}
    if notes:
        message["meta"] = notes
    return message


def translate_events(events):
    """(messages, receipt) for one OpenHands event list."""
    events = events if isinstance(events, list) else []
    by_id = {e.get("id"): e for e in events if isinstance(e, dict)}
    answered = {e.get("cause") for e in events if isinstance(e, dict) and e.get("observation")
                and (e.get("tool_call_metadata") or {}).get("tool_call_id")}
    out, said, r = [], set(), new_receipt()
    for e in events:
        r["events"] += 1
        if not isinstance(e, dict):
            r["set_aside"]["not an event"] += 1
            continue
        kind, args = e.get("action"), e.get("args") or {}
        if kind == "system":
            out.append({"role": "system", "content": args.get("content") or ""})
            r["written"] += 1
            if args.get("openhands_version"):
                r["framework_versions"][f"OpenHands {args['openhands_version']}"] += 1
        elif kind == "message":
            role = "user" if e.get("source") == "user" else "assistant"
            out.append(with_meta({"role": role, "content": args.get("content") or ""}, time=e.get("timestamp")))
            r["written"] += 1
        elif kind:
            if e.get("id") in answered:
                r["written"] += 1                # written together with its result
            else:
                r["set_aside"][f"action: {kind}"] += 1
        elif e.get("observation"):
            tcm = e.get("tool_call_metadata") or {}
            if not tcm.get("tool_call_id"):
                if e.get("observation") == "error" and e.get("source") == "agent":
                    out.append(with_meta({"role": "error", "content": e.get("content") or ""},
                                         time=e.get("timestamp")))
                    r["written"] += 1
                    r["malformed_calls"] += 1
                else:
                    r["set_aside"][f"result: {e.get('observation')}"] += 1
                continue
            action = by_id.get(e.get("cause")) or {}
            rid, text, name, arguments = raw_call(tcm)
            if arguments is None:
                name, arguments = tcm.get("function_name"), rebuilt_arguments(action)
                r["calls_rebuilt"] += 1
            else:
                check_edit(arguments, action, r)
            resp = tcm.get("model_response") or {}
            first = rid is None or rid not in said
            if not isinstance(text, str) or not text:
                text = (action.get("args") or {}).get("thought") or ""
            said.add(rid)
            if resp.get("model") and first:
                r["models"][resp["model"]] += 1
            usage = resp.get("usage") or {}
            tokens = ({"prompt": usage.get("prompt_tokens"), "completion": usage.get("completion_tokens")}
                      if first and usage else None)
            result = e.get("content") if isinstance(e.get("content"), str) else ""
            extras = e.get("extras") or {}
            if e.get("observation") == "run":
                meta = extras.get("metadata") or {}
                prefix, suffix = meta.get("prefix") or "", meta.get("suffix") or ""
                restored = False
                if prefix and not result.startswith(prefix):
                    result, restored = prefix + result, True
                if suffix and not result.endswith(suffix):
                    result, restored = result + suffix, True
                r["exit_lines_restored"] += restored
            files = {}
            if e.get("observation") == "edit" and extras.get("old_content") is not None \
                    and extras.get("new_content") is not None:
                files = {"file_before": extras["old_content"], "file_after": extras["new_content"]}
            out.append(with_meta({"role": "assistant", "content": text, "tool_calls": [
                {"id": tcm["tool_call_id"], "function": {"name": name, "arguments": arguments}}]},
                time=action.get("timestamp") or e.get("timestamp"), tokens=tokens,
                shared_response=None if first else True))
            out.append(with_meta({"role": "tool", "content": result, "tool_call_id": tcm["tool_call_id"]},
                                 time=e.get("timestamp"), **files))
            r["written"] += 1
            r["calls"] += 1
        else:
            r["set_aside"]["unknown event"] += 1
    return out, r


def events_to_messages(events):
    return translate_events(events)[0]


def run_record(run_id, source, messages=None, observations=None, receipt=None, model=None, outcome_label=None,
               patch=None, task=None, collection=None):
    receipt = receipt or new_receipt()
    if model is None and receipt["models"]:
        model = receipt["models"].most_common(1)[0][0]
    return {"id": run_id, "task": task or run_id, "collection": collection, "source": source, "model": model,
            "outcome": outcome_label,
            "patch": patch, "messages": messages, "observations": observations, "receipt": receipt}


def swehero(paths, model=None):
    """Runs from SWE-Hero parquet shards (no task outcomes: the dataset does not include them)."""
    import pyarrow.parquet as pq

    for path in paths:
        table = pq.read_table(path, columns=["trajectory_id", "instance_id", "dataset", "trajectory", "model_patch"])
        for row in table.to_pylist():
            msgs = row["trajectory"]
            r = new_receipt()
            r["events"] = r["written"] = len(msgs)
            r["calls"] = sum(len(m.get("tool_calls") or []) for m in msgs)
            yield run_record(row["trajectory_id"], "swehero", messages=msgs, receipt=r, model=model,
                             patch=row["model_patch"], task=row["instance_id"], collection=row["dataset"])


def openhands_events(set_dir, outcomes=None):
    """Runs from every `<set_dir>/<instance>/trajectory.json`."""
    for f in sorted(glob.glob(os.path.join(set_dir, "*", "trajectory.json"))):
        instance = os.path.basename(os.path.dirname(f))
        with open(f, encoding="utf-8") as fh:
            msgs, r = translate_events(json.load(fh))
        yield run_record(instance, "openhands_events", messages=msgs, receipt=r,
                         outcome_label=outcome(outcomes, instance), collection="SWE-bench Verified")


def result_text(rest):
    """The text inside a stored tool result such as "[{'type': 'text', 'text': '...'}]" (a Python literal), or
    None when the literal cannot be read."""
    try:
        parts = ast.literal_eval(rest)
    except (ValueError, SyntaxError, TypeError, MemoryError, RecursionError):
        return None
    if isinstance(parts, list):
        return "".join(p["text"] for p in parts if isinstance(p, dict) and isinstance(p.get("text"), str))
    return None


def read_observation_log(messages):
    """([(tool, text)], receipt) for an observation-only log."""
    out, r = [], new_receipt()
    for m in messages if isinstance(messages, list) else []:
        r["events"] += 1
        s = m.get("content") if isinstance(m, dict) else None
        found = TOOL_PREFIX.match(s) if isinstance(s, str) else None
        if found:
            text = result_text(found.group(2))
            if text is None:
                text = found.group(2)
                r["results_kept_raw"] += 1
            out.append((found.group(1), text))
            r["written"] += 1
        elif isinstance(s, str) and s.startswith("Action:"):
            r["set_aside"]["action not recorded"] += 1
        elif isinstance(m, dict) and m.get("role") in ("system", "user"):
            r["set_aside"]["prompt"] += 1
        else:
            r["set_aside"]["other message"] += 1
    return out, r


def observation_log(messages):
    return read_observation_log(messages)[0]


def observation_logs(set_dir, outcomes=None):
    """Runs from every `<set_dir>/<instance>.json` of an observation-only submission."""
    for f in sorted(glob.glob(os.path.join(set_dir, "*.json"))):
        instance = os.path.basename(f)[:-len(".json")]
        with open(f, encoding="utf-8") as fh:
            obs, r = read_observation_log(json.load(fh))
        yield run_record(instance, "observations_only", observations=obs, receipt=r,
                         outcome_label=outcome(outcomes, instance), collection="SWE-bench Verified")


def editor_outcome(text):
    """Sort one file-editor result: noop, missing, multiple, other_error, edited, created, undo, view or other.
    Checked in this order; "other" includes empty and unrecognized results."""
    t = (text or "").lstrip()
    if t.startswith(("ERROR", "Invalid", "No replacement", "Ran into")):
        if "must be different" in t:
            return "noop"
        if "did not appear verbatim" in t:
            return "missing"
        if re.search(r"[Mm]ultiple occurrences", t):
            return "multiple"
        return "other_error"
    if "has been edited" in t[:300]:
        return "edited"
    if t.startswith("File created successfully"):
        return "created"
    if t.startswith("Last edit to") and "undone" in t[:300]:
        return "undo"
    if VIEW.search(t[:400]):
        return "view"
    return "other"
